Request qua gateway

Mỗi thao tác là một request thật: trình duyệt → web server (giữ API key) → api.multi-region.io.vn → backend.

Tự gửi request đọc (danh sách, tìm kiếm, chi tiết, thỉnh thoảng một 404) cho tới khi bấm Dừng. Không sửa dữ liệu.

So Multi-Region với hệ thống bình thường chỉ có một Region cố định (cùng gateway, backend, key). Mỗi vòng đo theo thứ tự ngẫu nhiên: chặng trình duyệt → gateway của domain chung và của từng Region, cộng request thật qua hai hệ thống (nhãn 1R). Kết quả là trung vị, kèm p95.
